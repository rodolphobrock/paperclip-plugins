# paperclip-plugin-apprise

Notifications for Paperclip events to 100+ services via apprise-api. Uses [apprise-api](https://github.com/caronc/apprise-api).

> Work in progress. Not published yet.

See the [design spec](../../docs/specs/2026-09-27-notify-plugins-design.md).

## Local install

```bash
pnpm --filter paperclip-plugin-apprise build
paperclipai plugin install ./packages/plugin-apprise
```
