# paperclip-plugin-ntfy

Push notifications for Paperclip events via ntfy. Uses [ntfy](https://ntfy.sh).

> Work in progress. Not published yet.

See the [design spec](../../docs/specs/2026-09-27-notify-plugins-design.md).

## Local install

```bash
pnpm --filter paperclip-plugin-ntfy build
paperclipai plugin install ./packages/plugin-ntfy
```
